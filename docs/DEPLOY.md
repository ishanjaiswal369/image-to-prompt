# Deploying Image to Prompt

Free stack: **Neon** (Postgres) → **Render** (backend, Docker) → **Chrome Web Store** (extension).

## 1. Database — Neon

1. Sign up at <https://neon.tech> → **New project** → region **AWS Asia Pacific (Singapore)**.
2. On the project dashboard → **Connect** → turn **Connection pooling OFF** → copy the connection string
   (`postgresql://…neon.tech/neondb?sslmode=require`). This is `DATABASE_URL`.

Tables are created automatically on the backend's first boot (`prisma migrate deploy` runs on start).

## 2. Backend — Render

1. Sign up at <https://render.com> with GitHub.
2. **New → Blueprint** → pick `image-to-prompt` → it reads [`render.yaml`](../render.yaml).
3. Fill the two values it asks for: `DATABASE_URL` (from Neon) and `OPENROUTER_API_KEY`.
   JWT secrets and `ADMIN_TOKEN` are generated by Render.
4. **Apply**. When it's live, open `https://<your-service>.onrender.com/healthz` → `{"status":"ok"}`.

Free plan sleeps after ~15 min idle; the first request after that takes ~50 s.

## 3. Build the extension

```bash
# extension/.env
VITE_API_BASE_URL=https://<your-service>.onrender.com
```

```bash
npm run build:extension
```

Zip the **contents** of `extension/dist` (manifest.json at the zip root).

## 4. Chrome Web Store

1. <https://chrome.google.com/webstore/devconsole> → register ($5 one-time).
2. **New item** → upload the zip. Note the **item ID** shown (32 letters).
3. Fill the tabs with the text below, then **Submit for review**.

### Store listing

- **Name:** Image to Prompt
- **Summary (≤132 chars):** Right-click any image or select a screen region to get a structured, ready-to-use text-to-image prompt.
- **Category:** Tools · **Language:** English
- **Description:**

  ```
  Turn any image on the web into a detailed text-to-image prompt.

  • Right-click an image → "Analyze with Image to Prompt"
  • Or click the toolbar icon and drag to select any region of the screen
  • Get a ready-to-paste prompt plus structured fields: subject, composition, style, lighting, mood
  • Copy the prompt or the raw JSON with one click
  • History of your past prompts

  Works with Midjourney, Stable Diffusion, DALL·E, Flux and other image generators.
  Sign in with Google. New accounts get free credits.
  ```

- **Graphics:** icon `docs/store/store-icon-128.png`, small promo tile `docs/store/promo-small-440x280.png`,
  marquee `docs/store/promo-marquee-1400x560.png`, plus at least one **1280×800 screenshot** of the
  floating card showing a result.

### Privacy practices

- **Single purpose:** Generates a text-to-image prompt from an image the user selects.
- **Permission justifications:**
  - `contextMenus` — adds the "Analyze with Image to Prompt" item when right-clicking an image.
  - `activeTab` — captures the visible tab only after the user clicks the toolbar icon, for region select.
  - `scripting` — injects the floating result card and the region-select overlay into the current tab after a user action.
  - `storage` — keeps the user's sign-in session tokens locally.
  - `identity` — Google sign-in via `chrome.identity.launchWebAuthFlow`.
- **Remote code:** No, I am not using remote code.
- **Data usage — collects:** Personally identifiable information (email), Authentication information, Website content (the selected image / its URL).
  Tick all three certifications (not sold, not used for unrelated purposes, not used for creditworthiness).
- **Privacy policy URL:** <https://github.com/ishanjaiswal369/image-to-prompt/blob/main/PRIVACY.md>

## 5. Google sign-in for the store build

The store build gets a new extension ID, so Google must allow its redirect URL.

1. Google Cloud Console → **APIs & Services → Credentials** → open OAuth client `441916701308-3p2g…`.
2. **Authorized redirect URIs** → add `https://<store-item-id>.chromiumapp.org/` → Save.
3. **OAuth consent screen** → **Publish app** (move out of Testing) so any Google account can sign in.

No manifest change or re-upload needed — the client ID stays the same.

## 6. Allow the store build in CORS

Append the store origin to `EXTENSION_ORIGIN` in [`render.yaml`](../render.yaml)
(comma-separated) and push — Render redeploys automatically:

```yaml
value: chrome-extension://ldfpagaclmmaicecnpdmlbjgnempbapi,chrome-extension://<store-item-id>
```
