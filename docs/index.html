How it works

Three steps, no tab switching.

Everything happens in a floating card on the page you're already on. It stays open when you click away.

01

Pick an image

Right-click any image and choose Analyze with Image to Prompt, or click the toolbar icon and drag to select any region of the screen.

02

A vision model reads it

The image is analyzed for subject, framing, rendering style, light and atmosphere, each kept to its own field.

03

Copy and generate

Copy the finished prompt or the raw JSON in one click. Past results are saved in your history.

Install

Up and running in a minute.

Installed directly from the download, so it takes four quick steps instead of one click.

  1. Download the zipimage-to-prompt.zip from the latest release.
  2. Unzip it to a folder you'll keepChrome loads the extension from that folder, so don't delete it afterwards.
  3. Turn on Developer modeOpen chrome://extensions and flip the switch in the top-right corner.
  4. Load unpackedClick Load unpacked, pick the unzipped folder, then pin it from the puzzle-piece menu.

Good to know

  • Sign in with Google the first time you analyze an image. New accounts get free credits.
  • The backend runs on a free server that sleeps when idle, so the first analysis can take up to a minute. After that it's quick.
  • Screenshots you select are sent for analysis and never stored. See the privacy policy.

Under the hood

A small product, built like a real one.

A Manifest V3 extension talking to a typed Fastify API, with credits that can't be double-spent and AI calls that refund themselves when they fail.

Client

Chrome extension

MV3 service worker, context menu, region capture, React floating card

API

Fastify on Render

Google sign-in → JWT, per-user rate limits, Zod-validated routes

Data

Postgres on Neon

Prisma schema, append-only credit ledger, analysis history

AI

Vision model

OpenRouter or Gemini behind one adapter, structured JSON output

Credits as an append-only ledger

Every charge, refund and grant is its own row; the balance is their sum. Fully auditable, and a payment webhook becomes a single insert.

No overspending under concurrency

A per-user Postgres advisory lock serializes debits, so two simultaneous requests can't push a balance below zero. Covered by a concurrent-debit test.

Idempotent analysis requests

Each request carries an idempotency key. A retry replays the saved result instead of charging again; a failed AI call refunds automatically.

Swappable vision provider

Models sit behind one interface, chosen by an environment variable, with a backstop that rebuilds the prompt if a model returns it empty.
