(02)Demonstration

One image, read like a drawing.

Every result is built in three movements. The image is captured, a vision model reads it through five lenses, and the readings are composed into a single prompt.

(03)How it works

        

          Three movements.
          No tab switching.
        

        
Everything happens in a floating card on the page you're already on — and it stays open when you click away.

      


      
    
        
  1. 
          01
          
    Choose
    
          
    Right-click any image and pick Analyze with Image to Prompt — or click the toolbar icon and drag across any region of the tab.
    
          
    
            
          
    
        
    2. 
        
  2. 
          02
          
    Read
    
          
    A vision model studies the image and separates what it sees into subject, composition, style, lighting and mood — each kept to its own field.
    
          
    
            
          
    
        
    3. 
        
  3. 
          03
          
    Use
    
          
    Copy the finished prompt — or the structured JSON — in one click. Every result is saved to your history.

(04)Features

        

          Small tool,
          sharp output.
        

        
Prompts work in Midjourney, Stable Diffusion, DALL·E, Flux or any text-to-image model.

      

      

        
—Capabilities

        
    
          
  • A
    Right-click analysis
    Any image on any page, straight from Chrome's context menu.
    • 
          
  • B
    Region select
    Click the toolbar icon and drag across anything visible in the tab — frames, canvases, layouts.
    • 
          
  • C
    Prompt and JSON
    A paste-ready paragraph for image models, plus structured JSON for your own tools and pipelines.
    • 
          
  • D
    History
    Every analysis is saved to your account, ready to revisit and copy again.

(05)Install

          

            Four steps,
            one minute.
          

          
Image to Prompt is distributed directly rather than through the Web Store, so it installs with Chrome's developer mode.

          

            
              Download image-to-prompt.zip

(06)Technology

        

          Built like a product,
          not a prototype.
        

        
A Manifest V3 extension talking to a typed Fastify API — with credits that can't be double-spent and AI calls that refund themselves when they fail.

      


      

        
5
Analysis fields per image

        
2
Ways to capture — right-click or region

        
20
Free credits for every new account

        
0
Double charges — every request is idempotent
